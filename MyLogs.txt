PROJECT LOG

Project goal
This project is for a low altitude drone that flies in cities at about truck height.
The drone needs to understand what is around it so it can avoid objects safely.
The first phase of the project is to build a semantic segmentation model using the Cityscapes fine annotation dataset.

Dataset plan
The dataset folder is `gtFine_trainvaltest`.
The `gtFine_trainvaltest\gtFine\test` folder contains black images (privacy), so it will not be used.

Partitioning (finalized)
- Training: use the entire `gtFine_trainvaltest\gtFine\train` folder.
- Validation: use the first half of the `gtFine_trainvaltest\gtFine\val` folder.
- Testing: use the second half of the `gtFine_trainvaltest\gtFine\val` folder.

Note: These three partitions are disjoint — no image appears in more than one partition.

Phase 3 — Latency Bug Root Cause & Fix (2026-05-14):
- CRITICAL BUG IDENTIFIED: The reported YOLO latency of 76.71 ms vs ResNet50's 39.76 ms was a measurement methodology mismatch, NOT a true model speed issue.
- Root cause breakdown:
  1. ResNet50 measured: torch.cuda.synchronize() + time() around forward pass ONLY (no I/O, no pre/post processing inside timing window).
  2. YOLOv8n-seg measured: wall-clock time() around model.predict(source=path) which includes:
     - Disk I/O (reading the image file inside the timed window)
     - Non-Maximum Suppression (NMS) post-processing
     - Ultralytics Results object construction and Python dispatch overhead
     - No GPU warm-up (cold-start GPU JIT penalty on first N images)
- Fix implemented: Created `src/yolo_latency_fixed.py` which:
  - Loads and preprocesses images OUTSIDE the timed window
  - Calls model.model(tensor) (raw PyTorch backbone, no NMS)
  - Uses torch.cuda.synchronize() before and after each forward pass
  - Runs 5 GPU warm-up passes before measurement begins
  - Appends a yolov8n-seg-fixed FINAL row to the shared CSV
- Additional fixes:
  - Added `src/trim_yolo_dataset.py` for dataset trimming utility
  - Fixed `src/visual_grid.py` to use run2 baseline weights (resnet50_Run2_Epoch5.pth) and train_trimmed YOLO weights
  - Updated `cityscapes_trimmed.yaml` for trimmed dataset training
